# MDP-GOVERNANCE-001

## Authority

LEANDRO is the final human authority.

MESTRE orchestrates the mission under MCF methodology.

No agent may silently replace an explicit LEANDRO decision.

## Canonical-state rule

Repository state overrides chat memory whenever the repository can provide verifiable project state.

## Change control

New findings are classified as:
- BLOCKER
- REQUIRED_FOR_ACCEPTANCE
- FUTURE_OR_IMPROVEMENT

Only the first two may expand the current boundary automatically.

## Evidence rule

A phase or slice is not complete merely because code or documentation exists. Completion requires the corresponding acceptance evidence and gate.

## Sensitive-data rule

Real sensitive data is prohibited until Pilot Readiness and explicit HUMAN_GATE authorization.

## AI rule

AI is never the canonical source of autobiographical truth. Evidence, ledger and governed projections remain authoritative.
